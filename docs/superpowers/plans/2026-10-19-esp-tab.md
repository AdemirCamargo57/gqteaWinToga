# ESP Tab (3D Molecular Viewer) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Move the ESP tool into an **ESP** tab of the 3D Molecular Viewer. The ESP surface is drawn in the viewer's own GL window, and the tab adds an ESP cube export (plus an optional density cube on the same grid).

**Architecture:**
- The ESP drawing code moves from `espViewer.ESPSurfaceViewer` into a reusable GL-only `espSurfaceLayer.ESPSurfaceLayer`. `ESPSurfaceViewer` (still used by Fukui) delegates to it.
- `MolecularViewerUI` owns another layer and draws it through its hook overrides.
- `ElectrostaticSurfacePotentialUI` becomes `ESPTabController`, which builds a tab instead of a window.
- The cube export is headless in `ESPSurfaceAnalyser`.

**Tech Stack:** Python 3.13, numpy, PyOpenGL, toga-winforms 0.5, pytest.

**Spec:** [docs/superpowers/specs/2026-10-19-esp-tab-design.md](../specs/2026-10-19-esp-tab-design.md)

## Global Constraints

- Baseline: the 4 known failures (meanResidenceTime UI test, three plotter table-style tests) are not regressions.
- `tests/test_espViewer.py` passes **unchanged** (it pins Fukui's viewer). The Fukui tool's code is not edited.
- `espSurfaceLayer.py` imports neither Toga, GLFW nor molecularViewer. `electrostaticSurfacePotential.py` must not import molecularViewer or espViewer at module level.
- The base `MolecularViewer` hooks stay empty.
- Cube files are written through the existing `cubeFile.write_cube` (bohr, one spacing).
