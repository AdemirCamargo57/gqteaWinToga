# QTAIM Topology Analysis Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A QTAIM tab in the 3D Molecular Viewer. It finds the critical points of ρ in a Gaussian `.fchk`, computes their properties, traces bond and ring paths, writes `<stem>_QTAIM.txt`, draws everything in 3D, and plots a Multiwfn-style 2D plane map. Results agree with Multiwfn 2026.7.15.

**Architecture:** Toga-free numerical core (`gaussianWavefunction` derivatives → `qtaimTopology` → `qtaimAnalysis`), compiled kernels in the existing `densityNumba`, an OpenGL-only `qtaimLayer`, a Toga `qtaimTab` controller, and one new plot-viewer manifest shape drawn by `displayPlots.draw_plane_map`.

**Tech Stack:** Python 3.13, numpy, scipy (`cKDTree`), numba (optional), PyOpenGL, Toga 0.5 (WinForms), matplotlib (Agg / TkAgg viewer), pytest.

**Spec:** [docs/superpowers/specs/2026-10-20-qtaim-design.md](../specs/2026-10-20-qtaim-design.md)

## Global Constraints

- Input is `.fchk`/`.fch` through `gaussianWavefunction.read_fchk`; the density is `Total SCF Density` (`gw.DENSITY_SECTION`).
- Numerical modules work in **bohr**. Å appears only in the report, the tab and the views. `BOHR_RADIUS_ANGSTROM = 0.529177210544`, repeated locally and tested equal to `coordinateConverter.BOHR_RADIUS_ANGSTROM`.
- Toga is imported only by `qtaimTab.py`. `qtaimLayer.py` imports OpenGL but not Toga, GLFW or `molecularViewer`. Subprocess tests keep `toga` out of `qtaimTopology`, `qtaimAnalysis` and `qtaimLayer`.
- Numba is used wherever it helps, **always optional**:
  - kernels live only in `densityNumba.py`, and `NUMBA_KERNEL_MODULES` stays `{"espNumba.py", "densityNumba.py", "solventPackingNumba.py", "volumeNumba.py"}`;
  - every caller takes `use_numba: Optional[bool] = None` (None = if installed);
  - the numpy fallback agrees to ≤ 1e-12 relative.
- Multiwfn 2026.7.15 defaults:
  - CP search: max_iterations 120, step_scale 1.0, gradient_tolerance 1e-6, displacement_tolerance 1e-7, min_cp_distance 0.03 bohr, vdw_cutoff_scale 1.5, singular_determinant 5e-22, trust_radius None.
  - Paths: max_points 451, step 0.03 bohr, stop_distance 0.05 bohr.
  - In nuclear-seed mode the gradient criterion is waived.
- Property definitions: K = G − ¼∇²ρ; V = −G − K; H = G + V = −K; ε = λ₁/λ₂ − 1; η = |λ₁|/λ₃ (λ₁ ≤ λ₂ ≤ λ₃).
- Colours.
  - 3D: (3,−3) magenta, (3,−1) orange, (3,+1) yellow, (3,+3) green, bond paths brown, labels cyan.
  - 2D: (3,−3) brown, (3,−1) blue, (3,+1) orange, (3,+3) green, bond paths bold dark brown, interbasin deep blue. Nothing more than 0.5 bohr from the plane is shown.
- User errors are `ValueError` with a specific message; the UI shows them in `toga.ErrorDialog`; nothing raises out of an async handler. A `progress` callback that raises is swallowed.
- Interactive figures only: no PNG beside the user's data (`save_png=False` recipe); the manifest `<stem>_QTAIM_map.json` is written to the output folder.
- Tests instantiate the logic classes; the UI is tested headless via `__new__` + stub widgets. Baseline: four tests fail on `main` (see CLAUDE.md); compare against that.
- Commit after each task. Messages end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

def test_kinetic_g_is_half_sum_of_gradient_products():
    # G = 1/2 sum_ab P_ab grad(chi_a).grad(chi_b), checked against an explicit einsum
    wfn = gw.read_fchk(FCHK / "water_631gd_6d.fchk")

    assert np.allclose(gw.density_derivatives(wfn, POINTS, use_numba=False).kinetic_g, g, rtol=1e-12)

- [ ] **Step 3: Implement.** Per primitive, the 1D factors for power `n` along one axis are:
  - `f0 = t^n`
  - `f1 = n t^(n-1) - 2α t^(n+1)`
  - `f2 = n(n-1) t^(n-2) - 2α(2n+1) t^n + 4α² t^(n+2)` (terms with a negative power are zero)

  The derivative with powers `(p, q, r)` is `N_comp · Σ_k c_k e^{-α_k r²} · F_p(x) F_q(y) F_r(z)`. Contraction with `P = wfn.cart_density` uses BLAS products formed once per chunk:

```python
def _contract(ao, P, order):
    A = ao[:, 0]; AP = A @ P
    rho = np.einsum("pi,pi->p", AP, A)
    DP = [ao[:, k] @ P for k in (1, 2, 3)]
    grad = 2.0 * np.stack([np.einsum("pi,pi->p", AP, ao[:, k]) for k in (1, 2, 3)], axis=1)
    g = 0.5 * sum(np.einsum("pi,pi->p", DP[k], ao[:, 1 + k]) for k in range(3))
    hess = None
    if order >= 2:
        hess = np.empty((len(A), 3, 3))
        for k, (a, b) in enumerate(SECOND_PAIRS):
            v = 2.0 * (np.einsum("pi,pi->p", DP[a], ao[:, 1 + b]) + np.einsum("pi,pi->p", AP, ao[:, 4 + k]))
            hess[:, a, b] = hess[:, b, a] = v
    return rho, grad, hess, g
```

### Task 3: CP model, seeds, Newton search, merge, classification

**Files:**
- Create: `qtaimTopology.py`
- Test: `tests/test_qtaimTopology.py`

**Interfaces:**
- Consumes: `gw.density_derivatives`.
- Produces:
  - `CP_TYPES = ("(3,-3)", "(3,-1)", "(3,+1)", "(3,+3)")`, `NCP, BCP, RCP, CCP = CP_TYPES`.
  - Modes: `MODE_NUCLEI, MODE_PAIRS, MODE_TRIANGLES, MODE_TETRAHEDRA = 2, 3, 4, 5`; `MODE_LABELS = {2: "nuclei", 3: "atom pairs", 4: "triangles", 5: "tetrahedra"}`.
  - `@dataclass CPSearchParameters` with the Multiwfn defaults; `validate()` raises `ValueError` naming the field.
  - `@dataclass PathParameters(max_points=451, step=0.03, stop_distance=0.05)`, also with `validate()`.
  - `@dataclass CPProperties(rho, laplacian, gradient_norm, g, k, v, h, eigenvalues (3,), eigenvectors (3,3) columns, ellipticity, eta)`, with properties `v_over_g` and `h_over_rho`.
  - `@dataclass CriticalPoint(position (3,) bohr, kind: str, properties: CPProperties, assignment: Optional[Tuple] = None, index: int = 0)`. Assignment shapes: `("atom", i)`, `("nna",)` (NCP); `("pair", i, j)` (BCP, filled from bond paths); None otherwise.
  - `cp_properties(dd: DensityDerivatives, i) -> CPProperties` (from row i).
  - `classify(eigenvalues, zero=1e-10) -> Optional[str]` (None = degenerate).
  - `seeds_nuclei(coords)`, `seeds_combinations(coords, vdw_radii_bohr, size, scale) -> np.ndarray` (sizes 2/3/4). Pairs come from `cKDTree.query_pairs(max_cutoff)`, filtered by each pair's own cutoff. Triangles and tetrahedra come from cliques of that pair graph (sorted, deterministic).
  - `newton_search(wfn, seeds, params, nuclear=False, use_numba=None, progress=None) -> Tuple[List[np.ndarray], int]` returns the converged positions and the degenerate count. It is batched:
    - `step = -params.step_scale * solve(H, g)`, capped at the trust radius if set;
    - drop a seed when `|det H| < singular_determinant` or `rho < MIN_CP_DENSITY` (1e-8);
    - converged when `|step| < displacement_tolerance` and (`nuclear` or `|g| < gradient_tolerance`) — the `|g|` used is the one at the point the step started from.
  - `merge_critical_points(candidates, existing, min_distance) -> List[np.ndarray]`: the first-found point wins.
  - `poincare_hopf(counts: Dict[str, int]) -> Tuple[int, bool]` returns the sum and whether it equals 1.
  - `assign_nuclear_cps(cps, coords) -> None`: nearest nucleus within `NNA_DISTANCE = 0.3` bohr, else `("nna",)`.
  - `vdw_radii_bohr(atomic_numbers) -> np.ndarray` from `AtomicData.vdw_radii` (Å; `DEFAULT_VDW_RADIUS` = 2.0 Å when missing) / `BOHR_RADIUS_ANGSTROM`.
  - `find_critical_points(wfn, modes, params, use_numba=None, progress=None) -> Tuple[List[CriticalPoint], List[str]]` runs the modes in ascending order and returns the CPs ordered NCP (by assigned atom, NNAs last) → BCP → RCP → CCP (discovery order within a type), with 1-based `index` set, plus the notes (degenerate count).

### Task 4: Path tracing (bond and ring paths)

**Files:**
- Modify: `qtaimTopology.py`
- Test: `tests/test_qtaimTopology.py`

**Interfaces:**
- Produces:
  - `@dataclass TopologyPath(kind: "bond"|"ring", start_cp: int, end_cp: int, points: np.ndarray (m,3) bohr)`, from the start CP's position through the end CP's position, with a `length` property (sum of segment lengths).
  - `trace_paths(wfn, starts, direction, targets, params, plane=None, use_numba=None) -> List[Optional[Tuple[np.ndarray, int]]]`:
    - batched RK4 on `direction * ∇ρ/|∇ρ|` with step `params.step`;
    - a path stops when within `stop_distance` of a target (cKDTree);
    - None when `max_points` is reached or `|∇ρ| < 1e-12`;
    - `plane = (origin, u, v)` projects the gradient into the plane (2D map).
  - `bond_paths(wfn, cps, params, ...) -> Tuple[List[TopologyPath], List[str]]`:
    - each BCP is displaced `±params.step` along its λ₃ eigenvector, then ascends to the NCPs;
    - both halves must arrive;
    - sets the BCP's `assignment = ("pair", i, j)` from the two NCPs' atoms (NNA → `-1`), with i < j as in the report;
    - notes count the BCPs whose paths did not complete.
  - `ring_paths(...)`: only when CCPs exist. Each RCP is displaced ±step along λ₁, then descends to the CCPs. Halves that do not arrive are silently dropped (they leave to infinity, which is normal).
