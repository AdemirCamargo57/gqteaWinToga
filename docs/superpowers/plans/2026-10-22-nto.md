# Natural Transition Orbitals (NTO tab) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A new NTO tab in the 3D Molecular Viewer that builds natural transition orbitals of a CIS/TDA/TD excited state from a Gaussian `.fchk` + `.log`, lists their weights, draws hole/particle ± isosurfaces, and exports cubes, an NTO `.fchk` and a report, validated against Multiwfn 2026.7.15.

**Architecture:** Three Toga-free modules (`excitationData` parses the excitation file, `ntoAnalysis` does the SVD, grids and outputs, `gaussianWavefunction` gains MO coefficients and `orbital_values`) under one Toga module (`ntoTab`), which draws through a second `cubeRender.CubeSceneLayer` (`viewer.nto_layer`) using the Cube tab's `CubeEntry` mesh cache. One-way chain: `molecularViewer → ntoTab → {cubeTab, cubeRender, ntoAnalysis → {excitationData, gaussianWavefunction, molecularSurface, cubeFile, volumeData}}`.

**Tech Stack:** Python 3.13, numpy/scipy (LAPACK SVD), optional numba (existing `densityNumba` AO kernel only), Toga 0.5 WinForms, PyOpenGL, pytest.

**Spec:** [docs/superpowers/specs/2026-10-22-nto-design.md](../specs/2026-10-22-nto-design.md)

```python
def transition_matrix(state, spin, n_occ, n_mo):
    t = np.zeros((n_occ, n_mo - n_occ)); seen = set()
    for c in state.configurations:
        if c.spin != spin or c.deexcitation:
            continue
        if not (1 <= c.occupied <= n_occ < c.virtual <= n_mo):
            raise ValueError(f"Line {c.line}: {c.occupied} -> {c.virtual} is not an occupied -> virtual pair "
                             f"for {spin} ({n_occ} occupied of {n_mo} orbitals).")
        if (c.occupied, c.virtual) in seen:
            raise ValueError(f"Line {c.line}: the pair {c.occupied} -> {c.virtual} appears twice.")
        seen.add((c.occupied, c.virtual))
        t[c.occupied - 1, c.virtual - n_occ - 1] = c.coefficient
    return t

def natural_transition_orbitals(t, c_mo, n_occ, factor, spin):
    u, s, vt = np.linalg.svd(t, full_matrices=True)
    for k in range(len(s)):
        j = int(np.argmax(np.abs(u[:, k])))
        if u[j, k] < 0:
            u[:, k] *= -1.0; vt[k] *= -1.0
    v = vt.T
    return NTOSet(spin, n_occ, factor * s ** 2, u, v, c_mo[:, :n_occ] @ u, c_mo[:, n_occ:] @ v)
```
