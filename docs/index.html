gqteaWinToga

A Windows toolkit for preparing, visualizing and analyzing molecular simulations.

Build inputs for Gaussian 16, CPMD, Quantum ESPRESSO cp.x, ORCA and surface hopping runs, then turn the trajectories they produce into bond distributions, radial distribution functions, residence times, power spectra and rate constants. From Gaussian wavefunctions, show molecular orbitals, map the electrostatic potential onto molecular surfaces, find bond and ring critical points with QTAIM, take excited states apart with natural transition orbitals and hole–electron analysis, and find the reactive sites of a molecule with Fukui functions, all from one window.

Download for Windows

Free and open source, MIT license. Windows 10 or 11, 64-bit.

Release notes and earlier versions

What's inside

The program's main window groups its tools into five tabs. Each tool opens its own window: choose your files, enter the parameters, and run.

Measure geometry along a trajectory, usually a CPMD TRAJEC.xyz, and get averages, distributions and free-energy profiles.

  • Bond length analysis
  • All bond distances at once, solute only or the whole system
  • Bond angle and all bond angles
  • Dihedral angle and all dihedral angles
  • Hydrogen bond analysis
  • Comparison of geometric parameters between two runs, for example isolated versus solvated, with MAE and RMSD
  • For the all-at-once tools: pick the atoms or whole molecules to analyze by clicking them in a 3D view

Generate input decks from an XYZ geometry, ready to edit and run in the simulation program.

  • CPMD inputs for wavefunction optimization, equilibration and production runs
  • Surface hopping input builder
  • Molecular collision setup
  • Quantum ESPRESSO cp.x input builder
  • ORCA input builder
  • gqteaMD input builder
  • Gaussian 16 input builder in the style of GaussView: every common job type, ground and excited states, solvation, linked steps, reopening of .gjf files and the Fukui N, N+1 and N−1 job, plus a formchk script (new in 1.7.0)

Analyze solvation structure and dynamics, and build the boxes to simulate them in.

  • Radial distribution function
  • Mean residence time, by the statistical (survival function) and the classical method
  • Velocity autocorrelation function and power spectrum
  • Single-solute solvent box
  • Mixture of two solvents
  • Shared-wall double solvent box
  • For all three boxes: faster packing, an optional periodic pre-optimization that removes close contacts, the system's charge, electron count and spin multiplicity, and a live view of the box as it is built

Kinetics from simulation data.

  • Classical rate constant

Visualization, plotting and the many small conversions a simulation project needs.

  • 3D molecular viewer: trajectory playback, measurements, atom and molecule selection, a molecular design canvas, and tabs for cube files, molecular orbitals, ESP, QTAIM, natural transition orbitals and excitation analysis (more)
  • Analysis of Fukui functions: f+, f−, f0 and the dual descriptor in 3D, with global and atom-condensed reactivity indices (more)
  • Vanderbilt USPP generator: runs the bundled runatom to make and test ultrasoft pseudopotentials, with a formatted file for CPMD and defaults for any element picked from a periodic table
  • Plots: CPMD and gqteaMD energy files, multi-column data, grouped bar charts of tables with text labels such as atom symbols, and saved figures (UV-Vis spectra, MO diagrams, QTAIM maps and more) reopened from their JSON files
  • Molecular axis alignment
  • Frame selection, including by interatomic distance range
  • Surface hopping geometry analyzer: separate frames by electronic state
  • CPMD input to XYZ, and cp.x .pos to trajec.xyz
  • Forces from cp.x .for files
  • Coordinate converter (file formats, Ångström ↔ Bohr) and unit converter

New in version 1.7.0

Gaussian 16 inputs, set up the GaussView way

The Gaussian 16 Input Builder on the Inputs tab is modelled on GaussView 6.1’s Gaussian Calculation Setup: choose the job, the method, the basis set and the solvent from panels, and watch the route line being written as you go. Load the geometry from an XYZ, Gaussian, MOL/SDF, MOL2, PDB or .fchk file.

  • Every common job. Energy, optimization to a minimum or a transition state, frequencies (with Raman, VCD or anharmonic options), Opt+Freq, IRC, relaxed scans, stability and NMR.
  • Ground and excited states. Hartree–Fock, DFT with dispersion corrections, semi-empirical, MP2, MP4, coupled-cluster and compound methods; TD-SCF, TDA, CIS and ZINDO excited states, with the option that prints the CI coefficients the NTO and Excitation tabs read.
  • Linked steps. Chain several steps in one input with --Link1--, for example an optimization followed by a TD-SCF single point in solvent. Each later step reads the geometry and orbitals from the checkpoint, and the builder checks that the checkpoint it reads is really written earlier.
  • Open input. Read an existing .gjf back into the panels, edit it and save it again.
  • Checked before writing. All problems are listed at once, with the step they belong to. Charge and spin multiplicity are never guessed, and combinations Gaussian 16 refuses, such as an IRC without force constants, are caught here instead of in the queue. Every job type was run through Gaussian 16 to a normal termination.
  • Ready for Linux. Relative file names and Linux line endings for Gaussian 16 under WSL or on a cluster, plus a formchk script that turns the checkpoints into the .fchk files this program analyzes.
  • Fukui functions job type. The former Fukui input builder is now one of the job types, and writes exactly the same files as before (more).

How to use it · What its messages mean

The 3D Molecular Viewer

One window for structures, trajectories and wavefunctions. Play an .xyz trajectory, measure it, draw a new molecule, or open a Gaussian .fchk and look at what its electrons do. The analysis tabs need no external program at run time; each was checked against Gaussian’s cubegen or Multiwfn. The viewer opens in about a second, and each analysis tab is built the first time you open it.

Display, Box, Dynamics, Measure

Trajectory playback, bonds detected per element pair, lengths, angles and dihedrals by clicking atoms. Ctrl+click selects an atom and Shift+click its whole molecule; show the selection alone and export it for one frame or the whole trajectory. Any background colour, and solid, transparent or mesh drawing for every surface on the canvas.

Manual

Design

Draw a molecule with the mouse on a 3D canvas, import or save XYZ, Gaussian, MOL/SDF, MOL2 and PDB files, set or freeze bond lengths, angles and dihedrals, add hydrogens, pre-optimize, and send it to the viewer.

Manual

Cube

Gaussian cube files of any kind as ± isosurfaces and a slice plane; add or subtract two grids, colour one cube’s surface by another (an ESP on its density), and save cubes and images.

Manual

Orbitals

Molecular orbitals of restricted, unrestricted and restricted open-shell wavefunctions, as GaussView shows them: an MO table with occupancies and energies, HOMO/LUMO and Next/Previous, phase isosurfaces or |φ|², an energy-level diagram, and cube export of a range such as HOMO-2:LUMO+2.

Manual

ESP

The electrostatic potential mapped on electron-density surfaces, with its maxima and minima found as Multiwfn finds them (more below).

Manual

QTAIM

Bader’s topology of the electron density: nuclear, bond, ring and cage critical points with ρ, ∇²ρ, ellipticity and the energy densities G, V and H; bond and ring paths; the Poincaré–Hopf check; and a 2D map of contours, gradient lines and bond paths in any plane.

Manual

NTO

Natural transition orbitals of CIS, TDA and TD excited states from the .fchk and the output of the same job: pair weights, hole and particle isosurfaces, cube files, an NTO .fchk for GaussView, and the UV-Vis spectrum of all the states.

Manual

Excitation

Hole–electron analysis of an excited state: the distance and overlap indices, MO, atom and fragment contributions, interfragment charge transfer, the Δr and Λ indices, and a classification (local, charge transfer, Rydberg-like) that shows its evidence.

Manual

ESP tab of the 3D viewer

Electrostatic potential on molecular surfaces

Open a Gaussian formatted checkpoint (.fchk or .fch, made with formchk) in the viewer’s ESP tab. It builds one or more electron-density isosurfaces, computes the electrostatic potential exactly at every surface point, and finds its maxima and minima the way Multiwfn does. The result is drawn the way GaussView draws a mapped ESP: red where the potential is negative, blue where it is positive.

  • Two quantities, kept apart. The surface is set by the electron density (default isovalue 0.0004 a.u.; several isovalues per run); the potential is what is mapped onto it, in a.u. or kcal/mol.
  • Exact potential. Analytic integrals over the Gaussian basis set (s to g functions, closed or open shell), matching Gaussian’s own cubegen to better than 10−6 a.u. If cubegen is installed, it can be used instead.
  • Surface extrema saved. Every global and local maximum and minimum, with its value in a.u. and kcal/mol, its position in Å, the nearest atom and the isovalue of its surface, goes to <name>_ESP_extrema.txt.
  • Fast. A small molecule takes a second or two; the optional numba package makes larger ones about five times faster.
  • Ready for a paper. Choose a black, white or grey background and export the 3D view as a PNG image, or save the potential and the density as cube files, which the Cube tab reopens as the same coloured surface.

Fukui functions: where a molecule reacts

Give the tool three Gaussian .fchk files of one molecule at one geometry: the neutral molecule (N electrons), its anion (N+1) and its cation (N−1). It computes the Fukui functions from the three electron densities and shows where an added electron goes and where a removed one comes from. In other words, it shows which atoms favour nucleophilic, electrophilic or radical attack.

  • All the conceptual-DFT descriptors. f+, f−, f0 and the dual descriptor on a 3D grid, saved as cube files; the global indices (ionization potential, electron affinity, electronegativity, hardness, softness, electrophilicity and nucleophilicity); and the same functions condensed to each atom.
  • No external program needed. The atom-condensed indices come from built-in Hirshfeld charges for elements H to Ar. They agree with Multiwfn to within 3×10−4, and the 3D functions agree with Multiwfn’s cube files to within 10−5 a.u.
  • Seen in 3D. Show each function as positive and negative isosurfaces, or mapped in colour on the molecule’s density surface with its maxima and minima. Atoms can be drawn as lines, balls and sticks, or space-filling spheres, with or without their numbers. In a solvated cluster, select the solute and show only its atoms and its part of the surfaces.
  • Checked before computing. The tool refuses files with different atoms, geometries, basis sets or methods, and it says why. Phenol takes about eight seconds; the optional numba package makes the density grid about four times faster.

Prepare the three calculations

The Gaussian 16 Input Builder (Inputs tab, job type Fukui functions) writes one Gaussian 16 input with three linked jobs: it optimizes the neutral molecule, then runs the anion and the cation as single points at exactly that geometry. It also writes a formchk script that converts the checkpoint files into .fchk files. You must enter the spin multiplicity of every state, because the builder never guesses one. When you then pick the neutral molecule’s file in the analysis tool, the anion and cation files are filled in for you.

Install

  1. Download the installer

    Use the download button above. You get a zip file named like gqteaWinToga-v1.7.0-INSTALLER.zip.

  2. Extract it

    Right-click the zip, choose Extract All, and open the extracted folder.

  3. Run the installer

    Double-click gqteaWinToga-…-INSTALLER.exe. It installs for your user account, so administrator rights are not needed. If Windows shows “Windows protected your PC”, choose More info, then Run anyway. The warning appears because the program isn't signed with a commercial certificate.

  4. Start the program

    Open gqteaWinToga from the Start menu, or from the desktop shortcut if you chose to create one.

Requirements

  • Windows 10 or 11, 64-bit
  • The graphics driver from your card's maker (Intel, NVIDIA or AMD). The 3D viewer needs OpenGL, which Windows' basic display driver doesn't provide.
  • The simulation programs themselves (CPMD, Quantum ESPRESSO, ORCA, Gaussian and so on) are installed separately. gqteaWinToga prepares and analyzes their files; the Orbitals, ESP, QTAIM, NTO, Excitation and Fukui function tools need only Gaussian’s .fchk files (and, for excited states, the job’s output), not Gaussian itself.
  • The USPP generator’s runatom program is included; nothing else needs to be installed for it.
Run from the source code instead

Requires Python 3.10 or newer (tested on 3.13) with the tcl/tk component. In PowerShell:

git clone https://github.com/AdemirCamargo57/gqteaWinToga.git
cd gqteaWinToga
python -m venv venv
.\venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -r installation_requirements.txt
python gqteaWinToga.py

Details are in the user manual.

Learn to use it

The user manual describes every tool, its input files and outputs, with worked examples such as finding a bond-length free-energy minimum, preparing a CPMD collision restart, grouping surface hopping frames by electronic state, locating the electrostatic potential minima of a molecule, reading a Fukui function figure of phenol, a QTAIM analysis of the hydrogen bond in the water dimer, the natural transition orbitals of uracil, classifying the excited states of a push–pull molecule and the frontier orbitals of benzene. Each analysis has a section on the theory and the formulas behind it.
